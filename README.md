# ExploratoryDataAnalysis_StatisticalAnalysis

The project covers different aspects of Data Cleaning, Data Analysis, EDA, Data Visualization, Statistical Analysis and Data Modeling.
All these have been greatly demonstrated on 3 different datasets, such as, **MovieLens**, **House Price prediction** and **Life Expectancy prediction** spanning different domains such as **Entertainment**, **Real Estate**, and **Healthcare**.

## About the Datasets:
**MovieLens Dataset**
- Performed Recommendation system using Singular Value Decomposition (SVD) and Cosine Similarity
- Identified top 10 closest movies to a given movie based on collaborative filtering techniques.

**House Price Prediction Dataset**
- Performed Feature analysis, data imputation, and multiple regression models
- Models applied are - Linear Regression, Polynomial Regression, RANSAC (Robust Regression)
- The RANSAC provided the best fit among all models based on R² scores.

**Life Expectancy Prediction Dataset**
- Carried out Preprocessing, feature encoding, outlier treatment, applied gradient descent algorithms
- Models employed are - Linear Regression, Stochastic Gradient Descent, Mini-Batch Gradient Descent (custom)
- The SGD model achieved the lowest Mean Squared Error (MSE ≈ 4.84), making it the most effective.

## Features applied: 
- Handling of different file formats (e.g., .dat ➝ .csv)
- Statistical imputation (mean, median, mode) & handling zero values
- Dimensionality reduction using SVD
- Feature transformation & encoding
- Outlier detection using IQR
- Correlation matrix analysis & heatmaps
- Implementation of machine learning models using scikit-learn
- Manual implementation of Mini-Batch Gradient Descent
